# Course Library

The library is a git checkout at `${COURSE_LIBRARY:-$HOME/Developer/course-library}` (repo `RobertoVillegas/course-library`, private). Each course folder has a `README.md` (modules, lessons, one-line overviews, top takeaways) and `lessons/NN-<lesson>.md` with fixed sections: Overview, Outline, Core Concepts, Step-by-step Explanation, Examples / Exercises, Common Pitfalls, Key Takeaways.

## Workflow

1. Set `lib="${COURSE_LIBRARY:-$HOME/Developer/course-library}"`. If it is missing, clone it there with `git clone git@github.com:RobertoVillegas/course-library.git "$lib"`; otherwise run `git -C "$lib" pull --ff-only -q` once per session.
2. Search before reading: `python3 "$lib/search.py" "<words>"`. Results are BM25-ranked lesson paths with snippets. Add `--course <text>` to stay in one course and `--limit N` for more. `--list` shows every course; `catalog.md` is the same list for humans.
3. Read the course `README.md` for orientation, then only the lesson files the answer needs.
4. If nothing matches, retry with synonyms, the course's own vocabulary, or fewer words. `--raw` accepts FTS5 syntax (`"exact phrase"`, `NEAR(a b, 5)`, `term*`).
5. Answer from the notes and cite the lesson path for each claim. The notes are generated summaries of videos and PDFs: content marked "unclear" was ambiguous in the source, so say so instead of filling the gap.

## Rules

- Do not copy the library into other repos or skills; link or quote what is needed.
- The library is read-only here. It is regenerated by `syllabus library` on devbox-gpu; fix content there, not in the checkout.
