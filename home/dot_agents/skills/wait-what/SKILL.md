name: wait-what
description: "Re-pitch the previous explanation with missing context and simpler language. Use only when the user explicitly invokes wait-what or says the explanation did not land."
---

The user did not follow your last explanation. Explain it again, in the language of the conversation:

- Start with the context they are missing: what problem this is, where we are in the task, and why it matters now.
- Use short sentences, one idea each. Use everyday words, and define any term the user has not used.
- Use the names the repository and the conversation already use for things. Do not introduce new names.
- Keep it shorter than the original. End with the one decision or fact they need from it.
